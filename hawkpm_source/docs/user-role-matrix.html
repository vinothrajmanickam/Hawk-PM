Rule Definitions

  • Admin is identified when the user's name contains "Vinoth" or the user ID equals admin. Admin has unrestricted edit and delete access across all projects.
  • Create Project is open to everyone — Admin, PM, Application Owner, and all other users can create projects.
  • Edit Project is granted to the Admin (all projects), and to a project's own Project Manager (matched by PM name or the creating PM's ID) and Application Owner (matched by owner name or a stakeholder marked as "Application Owner"). All others are view-only.
  • Delete Project is restricted to the Admin (Vinoth) only.
  • View Project is available to all authenticated users.

Sign-in Methods

  • Microsoft Entra ID (SSO): Users signing in via "Sign in with Microsoft" are assigned the default Stakeholder role; the name-based Admin check still applies (a user named Vinoth receives Admin rights).
  • Mock / development logins: Retained for testing role-based access — Admin (Vinoth), Project Manager (Deepan), Application Owner (Chandru), Regular User (Padma).
